# Task Manager API

A modern, type-safe REST API for managing tasks. This is a backend-focused portfolio project built to master server-side architecture, HTTP routing, and database integration.

## 🚀 Tech Stack
- **Runtime:** Node.js (ES Modules)
- **Language:** TypeScript
- **Framework:** Express
- **Development Tooling:** tsx (for fast development execution)

## 🛠️ Features (In Progress)
- [x] Basic HTTP Server Setup
- [x] CRUD operations for Tasks (GET, POST, PATCH, DELETE)
- [x] Data validation using Zod
- [x] Persistent storage with PostgreSQL & Prisma
- [x] Docker integration

## 📦 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/kubrak-j/task-manager-api.git
   cd task-manager-api
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the server in development mode:
   ```bash
   npm run dev
   ```
